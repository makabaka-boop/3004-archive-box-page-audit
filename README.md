# 纸质档案装盒页码核对台

纯前端、本地优先的档案装盒页码核对工具。支持档案增删改、CSV 原子导入、自动异常识别、问题处置、筛选、每盒区间视图、打印清单，以及 JSON 全量备份恢复。数据只写入当前浏览器 `localStorage`。

## 本地运行

```bash
npm install
npm run dev
```

测试与构建：`npm test`、`npm run build`。

## CSV 导入

文件须为 UTF-8 CSV，首行必须严格使用：

```text
档号,标题,年度,保管期限,盒号,起始页,结束页,申报页数,备注
```

除备注外均必填；年度与页数字段须为 0–999999 的整数。导入检查现有数据及批内重复档号、起止页合法性。任一行失败会显示行号并取消整批导入，不改变原数据。带逗号或双引号的文本请使用标准 CSV 引号规则。

## 核对与备份

自动识别重复档号、页码倒置、实际页数与申报页数不符、同盒区间重叠。问题可标记“已修正”或“确认保留”并填写说明；编辑档案后会重新检查并清除其旧处置。JSON 导入先完整校验，非法备份不会覆盖当前数据。

## 连续编页

在“每盒页码区间”面板点击“连续编页”，选择盒号并输入该盒起始页后先预览整盒重排结果：档案按当前起始页、结束页、档号稳定排序，依据每件申报页数依次生成首尾相接的新起止页，逐项展示原区间、新区间和将被清除的异常处置数量。确认前不改动任何数据与本地存储；起始页为空、不是非负整数、盒内有申报页数为零的档案，或任一新页码超过 999999 时会说明原因并禁止确认。预览生成后若同盒档案或其处置发生变化，预览会标记为过期，必须重新预览才能确认。确认后批量写入该盒档案、清除这些档案关联的旧处置，并自动重新检测异常、刷新统计与盒视图。

## 盒内盘点

库房核实实体盒内容时，在“每盒页码区间”每盒卡片下方的“盒内盘点”面板点击“开始盘点”：以一次盘点会话保存所选盒号、创建时间和当时盒内档案的快照（每个会话项生成独立标识并保留来源档案标识），快照中的盘点序号（从 1 开始）即期望摆放顺序。此后可连续输入或扫描档号逐件登记，每次成功命中都会记录一个从 1 开始递增、不可重复的**实物序号**：唯一命中直接分配，同一档号命中多件时面板列出各候选的盘点序号、题名和页码区间，仅在明示选中一件（歧义确认成功）后才分配下一个序号；空输入、档号不存在、重复扫描或取消候选均不消耗序号。扫描对档号两端空格不敏感：即使档案登记保留了档号首尾空格，扫描肉眼相同的档号仍正常命中（快照与档案登记原样保留空格）。刷新页面后从独立的 `archive-audit:inventory-sessions` 本地存储键恢复进度并继续编号；恢复时会自动修复残缺状态——仍有待盘项的完成标记回退为进行中、待盘项上残留的实物序号予以清空（序号只依据已成功命中项连续编号）、重复的会话项标识重新生成（歧义选中只登记所选那一件）。全部命中后自动完成，面板按档案逐项展示期望序号、实物序号和“一致/错位”结果，并汇总首个错位位置（第一件实物序号与盘点序号不一致的期望序号）；点击“重新盘点”会生成全新会话，实物序号重新从 1 开始。创建于实物序号功能上线前的旧会话照常显示原盘点进度，但会明确提示缺少实物序号、无法复核摆放顺序（不会误报为错位）。盘点只读写会话快照，档案登记、异常处置、连续编页与 JSON 备份内容均不被改写。

## 借阅台

库房把单件纸质档案临时交给查阅人时，在“档案清单”对应行点击“借阅”发起登记，在借阅台表单填写查阅人与预计归还日（YYYY-MM-DD）后确认。借阅记录以记录为核心对象，保存借出当时的档案快照（档号、题名、盒号、页码）、查阅人、借出时间、预计归还日和归还时间，写入独立的 `archive-audit:borrow-records` 本地存储键，刷新页面后该档案在清单中仍显示“借出中”。同一档案存在未归还记录时按档案标识拒绝重复借出；查阅人为空、预计归还日非法或早于借出当天时，在表单旁说明原因并保留已填写的内容；确认前目标档案已被删除或已被他处借出的，提示重新选择——所有失败操作都不产生记录。借阅台集中展示未归还记录与历史记录，对未归还项点击“归还”只补写归还时间，重复归还不改变原记录。此后编辑或删除档案不影响已产生的借阅历史（记录保存的是快照）。旧浏览器数据（无此键）按空列表直接加载；JSON 备份恢复不导入也不清除借阅记录。借阅台只读写借阅记录，档案登记、异常处置、盘点会话与连续编页均不被改写。

```bash
docker compose up --build -d
curl http://localhost:8084/health
docker compose down
```
